# TurkPhysics AI

Türk Dünyası universitetləri üçün AI dəstəkli fizika tədrisi və virtual laboratoriya platformasının interaktiv veb prototipi.

## Platformada

- Azərbaycan və türk dilləri arasında seçim
- Mexanika, elektrik və maqnetizm, dalğalar və rəqslər, istilik və termodinamika kurs kataloqu
- Dəyişənləri idarə olunan fizika simulyasiyaları
- Dərs qeydləri, təcrübə ssenariləri və tapşırıq nümunələri
- Fizika suallarına izahlı cavab verən AI köməkçisi üçün nümayiş interfeysi
- Mövzu üzrə qısa yoxlama sualları

## Açmaq

Layihə statik HTML prototipidir. `index.html` faylını brauzerdə açmaq kifayətdir; quraşdırma tələb olunmur.

## Qeyd

AI köməkçisi nümayiş rejimindədir və hazırda xarici AI xidmətinə qoşulmayıb. Kurs və laboratoriya məzmunu platformanın ilkin prototipini nümayiş etdirir; real universitet məlumatları və istifadəçi hesabları ilə inteqrasiya ayrıca hazırlanmalıdır.
