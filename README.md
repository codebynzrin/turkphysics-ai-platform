# TurkPhysics AI

Türk Dünyası universitetləri üçün AI dəstəkli fizika tədrisi və virtual laboratoriya platformasının interaktiv veb prototipi.

## Dizayn

Əsas panelin Figma dizaynı: [TurkPhysics AI — Dashboard](https://www.figma.com/design/6qiLn2zG7fOGwWH13d0oO7).

## Bölmələr

- İcmal: qısa başlanğıc paneli və tövsiyə olunan dərs
- Kurslar: dörd fizika mövzusu üzrə kurs planları
- Laboratoriya: dəyişənləri idarə olunan beş fizika simulyasiyası
- AI köməkçisi: fizika sualları üçün izahlı cavab nümayişi
- Resurslar: konspektlər, çalışma vərəqləri, təcrübə ssenariləri və yoxlama sualları
- İrəliləyiş: tamamlanan mövzuları işarələ; seçimlər bu brauzerdə saxlanır

Dil seçimi: Azərbaycan və türk dilləri.

## Açmaq

Statik HTML prototipidir. `index.html` faylını brauzerdə açmaq kifayətdir; quraşdırma tələb olunmur.

## Qeyd

AI köməkçisi nümayiş rejimindədir və xarici AI xidmətinə qoşulmayıb. İstifadəçi hesabı və buludda sinxronizasiya hələ inteqrasiya edilməyib. İrəliləyiş məlumatları yalnız cari brauzerdə saxlanır.
