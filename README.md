# TurkPhysics AI

Türk Dünyası universitetləri üçün AI dəstəkli fizika tədrisi və virtual laboratoriya platformasının interaktiv veb prototipi.

## Dizayn

Əsas panelin Figma dizaynı: [TurkPhysics AI — Dashboard](https://www.figma.com/design/6qiLn2zG7fOGwWH13d0oO7).

## Platformada

- Azərbaycan və türk dilləri arasında seçim
- Mexanika, elektrik və maqnetizm, dalğalar və rəqslər, istilik və termodinamika kurs kataloqu
- Dəyişənləri idarə olunan beş fizika simulyasiyası
- Dərs qeydləri, təcrübə ssenariləri və tapşırıq nümunələri
- Fizika suallarına izahlı cavab verən AI köməkçisi üçün nümayiş interfeysi

## Açmaq

Statik HTML prototipidir. `index.html` faylını brauzerdə açmaq kifayətdir; quraşdırma tələb olunmur.

## Qeyd

AI köməkçisi nümayiş rejimindədir və xarici AI xidmətinə qoşulmayıb. İstifadəçi hesabı və real öyrənmə statistikası hələ inteqrasiya edilməyib. Kurs və laboratoriya məzmunu ilkin prototipi nümayiş etdirir.
